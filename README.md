
# Data Science Case Study

This repository documents my hands-on learning journey in **Data Science** through practical case studies and Jupyter notebooks. The focus is on mastering data preprocessing, exploratory data analysis (EDA), feature engineering, and preparing data for machine learning.

---

## 📚 Topics Covered

### 1. Handling Missing Values
- Identifying missing values
- Removing rows and columns with missing data
- Mean, Median, and Mode Imputation
- Forward Fill (FFill)
- Backward Fill (BFill)

### 2. Exploratory Data Analysis (EDA)

#### Univariate Analysis
- Histograms
- Box Plots
- Count Plots
- Distribution Plots
- Summary Statistics

#### Bivariate Analysis
- Scatter Plots
- Correlation Analysis
- Pair Plots
- Heatmaps
- Categorical vs Numerical Analysis

### 3. Outlier Detection and Treatment
- Understanding Outliers
- Detecting Outliers using Box Plots
- IQR (Interquartile Range) Method
- Z-Score Method
- Removing Outliers
- Capping (Winsorization)
- Impact of Outliers on Machine Learning Models

### 4. Feature Engineering
- Creating New Features
- Feature Transformation
- Date & Time Feature Extraction
- Handling Skewed Data
- Feature Selection Basics

### 5. Feature Encoding
- Label Encoding
- One-Hot Encoding
- Ordinal Encoding
- Target Encoding (Introduction)

### 6. Feature Scaling
- Standardization (StandardScaler)
- Normalization (MinMaxScaler)
- Robust Scaling
- When and Why Feature Scaling is Important
